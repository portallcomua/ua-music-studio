UA MUSIC STUDIO 3.0.0
=====================

Автор: UA Server
Сайт: https://uaserver.pp.ua
Сторінка плагіна:
https://uaserver.pp.ua/ua-music-studio/

ОПИС
----

UA Music Studio — студія для роботи з музичними композиціями,
аналізу тональності, приблизного визначення акордів,
транспонування та особистої колекції композицій.

ВСТАНОВЛЕННЯ
------------

1. Завантажте папку ua-music-studio.
2. Перевірте структуру папок.
3. Заархівуйте папку ua-music-studio у ZIP.
4. У WordPress відкрийте:
   Плагіни → Додати плагін → Завантажити плагін.
5. Виберіть ZIP-архів.
6. Натисніть Встановити.
7. Активуйте плагін.

SHORTCODE
---------

[ua_music_studio]

Додайте shortcode на сторінку WordPress.

МОВИ
----

Мова інтерфейсу визначається мовою WordPress.
Підтримувані мови:
- Українська
- English

КОЛЕКЦІЯ
--------

Безкоштовний ліміт:
10 збережених композицій.

Після досягнення ліміту користувачеві пропонується
перехід до оплати через UA Pay Box.

Завантаження та прослуховування композицій без збереження
в колекцію не повинні обмежуватися лімітом колекції.

ВАЖЛИВО ПРО АУДІО
-----------------

Відтворення локальних аудіофайлів виконується у браузері.

Аналіз тональності, BPM та акордів є приблизним.
Результат залежить від якості запису, інструментів
та структури композиції.

Для якісного транспонування без зміни темпу потрібен
окремий алгоритм pitch shifting.

Для розділення вокалу та інструментів потрібна
сумісна AI-модель та адаптер її аудіоформату.

Для розпізнавання співу потрібна модель розпізнавання мовлення,
наприклад Whisper або сумісний модуль.

Для перекладу потрібна окрема модель перекладу
або зовнішній сервіс.

Ці AI-модулі не вважаються готовими лише після
встановлення основного плагіна.

АВТОМАТИЧНЕ ОНОВЛЕННЯ
---------------------

Для оновлення з GitHub необхідно:

   portallcomua/ua-music-studio

4. Додати ZIP-архів із точною назвою:
   ua-music-studio.zip

   версії плагіна.

вказані власник і назва репозиторію.
